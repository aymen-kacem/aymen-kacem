<h3>📌 Big Data Architecture for Fast & Changing Data Analysis</h3>
<p>
Designed a highly scalable, fault-tolerant multi-cluster architecture for real-time and batch data analysis.
</p>
<ul>
  <li>Data ingestion from APIs with Apache Kafka, consumed by Hadoop (HDFS), Kudu, and Spark</li>

  <li>Real-time processing with Spark Streaming, stored in Kudu for fast analytics</li>
